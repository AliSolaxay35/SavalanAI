# 🎓 Faradars Exercises

This Directory Contains Practical Exercises And Learning Implementations Completed During Medical Imaging And Deep Learning Studies Through Faradars.

## 📚 Exercises

The Exercises Cover Different Topics Related To Medical Imaging, Image Processing, Numerical Computing, And Deep Learning.

* **DICOM-FD** — Working With DICOM Medical Images
* **Heart-FD** — Cardiac Medical Image Analysis
* **NIFTI-FD** — Working With NIfTI Medical Images
* **Numpy-FD** — Numerical Computing And Array Operations
* **Pneumonia-FD** — Pneumonia Image Classification
* **Pre-Processing-FD** — Medical Image Pre-Processing
* **PyTorch-FD** — Deep Learning With PyTorch

## 🤖 Educational Models

Two Lightweight Models Were Developed As Part Of The Practical Exercises:

* `cardiac_unet_best.pth` — Cardiac Image Segmentation Model
* `pneumonia_cnn.pth` — Pneumonia Image Classification Model

These Models Were Created For Educational And Practice Purposes. Their Training Metrics And Final Evaluation Results Were Not Systematically Recorded.
